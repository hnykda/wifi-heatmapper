See where your Wi-Fi is weak.

Walk around with your laptop and click where you stand on a floor plan. Wi-Fi Heatmapper measures the signal, and the speed if you like, right there. A few rooms later you have a heat map of your home or office.

What it does

Answers the question “is it the Wi-Fi?” for every room, with numbers you can compare.

Signal strength everywhere
Each spot records the signal in dBm and percent, plus the access point, channel, band and PHY mode it was connected to.
Real speed, not just bars
Point it at an iperf3 server on your network and every spot also gets TCP and UDP throughput in both directions, jitter and lost packets.
Before and after
Fix the colour scale of each map, then survey again after moving the router or adding a mesh node. Same colours, same numbers.
Any floor plan
Upload an architect’s drawing, a screenshot from the map, or a phone photo of a pencil sketch. It does not need to be to scale.
Access points by name
Call aa:bb:cc:dd:ee:* “Upstairs mesh” and every band of that node shows up under one name in the table and export.
Stays on your computer
No account, no cloud, works offline. Surveys are plain JSON files. Export points as CSV and maps as PNG with a legend.

How it works

A survey of a flat takes about ten minutes.

  1. Pick a floor plan

    Use the bundled example or upload your own image in Settings. Each floor plan keeps its own survey.

  2. Click where you stand

    The app reads the Wi-Fi signal (and runs iperf3, if set up) and drops a coloured dot on that spot.

  3. Cover every room

    One or two spots per room, more in big ones and near the edges. Switch off or delete any odd reading.

  4. Read the heat maps

    Drag the radius until the dots merge into one surface, then download the maps you need.

Under the hood

The app uses what your system already has: CoreWLAN on macOS (through a small helper, no password), the Native Wifi API on Windows, and iw on Linux. Throughput comes from iperf3. The heat map is inverse-distance weighting drawn with WebGL. The details are on the how it works page.

macOS

macOS 11 or later

  • Apple silicon (.dmg)
  • Intel (.dmg)

Or with Homebrew, which installs iperf3 too:

brew install --cask hnykda/tap/wifi-heatmapper

Windows

Windows 10 or 11, x64

  • Installer for you (.exe)
  • Installer for all users (.msi)

Linux

x64 and ARM64, including Raspberry Pi

  • Debian, Ubuntu (x64 .deb)
  • Debian, Raspberry Pi OS (ARM64 .deb)
  • Any distribution (x64 AppImage)
  • Any distribution (ARM64 AppImage)

The apps are not signed, so macOS and Windows warn you the first time you open them. The install guide shows the two clicks it takes on each system, where your data is kept, and what has been tested so far.

Rather run it from source? With Node.js 20 or newer: 

git clone https://github.com/hnykda/wifi-heatmapper.git
cd wifi-heatmapper
npm install
npm run dev        # then open http://localhost:3000

There is also a Docker image for Linux hosts, and npm run dev:mock to try the app with made-up measurements on any machine. All files are on the releases page.

Free, and open to help

Wi-Fi Heatmapper is MIT licensed: no ads, no accounts, no paid tier. If it saved you an afternoon of guessing where to put the router, a star helps others find it.

Star on GitHub

  • Tell us how it went

    The desktop apps are young. Even “it just worked” helps: open a desktop app report with your system and what you tried.

  • Report a problem

    Open an issue with the details from the app’s About dialog (the “i” in the header) and a log if you have one.

  • Send a pull request

    Start with CONTRIBUTING.md or a good first issue. Mock mode runs the whole app without Wi-Fi, so any machine will do.
